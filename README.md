<h1> Splunk Basics - Did you SIEM? <br/>
This project documents my hands-on experience using Splunk to investigate suspicious web server activity in a simulated security environment. The analysis focuses on identifying indicators of compromise through log examination, including suspicious user agents, unusual IP activity, command injection attempts, directory traversal attacks, unauthorized access attempts, and potential web shell deployment.

Throughout the investigation, I utilized Splunk's search and filtering capabilities to trace attacker behavior, analyze HTTP requests and responses, and identify signs of command-and-control (C2) communication and possible data exfiltration.
